Python pipeline for Bloomberg BQuant

What was measured

A BQuant pipeline that won’t feed a backtest data it couldn’t have had.

It pulls through BQL in pieces small enough to finish, retries what fails, caches what it got, checks every price before anything is computed from it, and builds each date’s universe and earnings from what was known that day. I can’t run BQuant here, so it ran on simulated markets whose truth is known, through a stand-in for the bql module.

Checks before anything is computed

Each check returns the rows it flags. In research those rows are left out and listed; in production any of them stops the run before a file is written, so last night’s good data stays in place.

On the same markets with nothing planted, the checks raised 0 flags. They aren’t perfect: with smaller errors than they were tuned for, they found 30 of 30 bad prints of 40%, and 0 of 30 stale runs of 3 repeated days, because a run has to last 5 days to count. Lowering that threshold would start flagging thinly traded names.

Pulling through BQL

Queries follow the public BQL examples: a get(…) for(…) with(dates=range(…)) string, read back with bql.combined_df(bq.execute(query)). Large pulls are split by securities and by date window, each piece is retried with growing waits, and each result is cached by the hash of its query, so a rerun costs no BQL usage.

get(px_last, px_volume) for(['AAPL US Equity', 'MSFT US Equity']) with(dates=range(2024-01-01, 2024-12-31))

get(name) for(members('SPX Index', dates=2019-06-28))
import bql
from bqpipe.bql_source import BqlSource
from bqpipe import pipeline

src = BqlSource(bql.Service(), bql.combined_df,
                chunk=100, years=2, cache_dir="cache/")
pipeline.run(src, "SPX Index", "2014-01-01", "2023-12-31",
             actions, calendar, mode="production", out_dir="data/spx")

What was measured, and what wasn’t

Measured

  • 23 of 23 tests pass, and they catch 21 of 21 bugs planted one at a time.
  • Total returns rebuilt from raw prices, splits and dividends match the simulated truth to within 1e-12.
  • The bias table above: 20 markets, 4 versions each, same strategy code.
  • Check scores on planted errors, on clean data and on smaller errors, as listed.
  • Chunked, retried and cached pulls return identical rows. 30 of 30 browser checks on this page pass.

Not measured

  • No BQuant or BQL access. The bql stand-in mimics the response shape of public examples; query parameters such as price adjustment and currency need confirming in your BQuant.
  • No Bloomberg data: markets, prices and earnings are simulated, so the bias sizes are not estimates for any real index.
  • Fundamentals and corporate actions through BQL aren’t wired up yet; their field names depend on your entitlements.
  • Request limits and BQL usage costs on your account are unknown; chunk size and window are settings.
